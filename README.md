# Simple Linear Regression

## Overview

This project demonstrates **Simple Linear Regression**, a supervised machine learning technique used to model the relationship between one independent variable and one dependent variable.

The model learns a best-fit straight line from training data and uses it to predict numerical outcomes.

## Objectives

- Understand the fundamentals of regression.
- Explore the relationship between an input feature and a target variable.
- Train a linear regression model.
- Generate predictions for numerical data.
- Visualize the relationship between actual observations and the fitted regression line.

## Algorithm

Simple Linear Regression models the relationship between two variables using:

\[
y = b_0 + b_1x
\]

Where:

- `y` is the predicted target value.
- `x` is the independent variable.
- `b₀` is the intercept.
- `b₁` is the regression coefficient.

## Workflow

1. Load and inspect the dataset.
2. Identify the independent and dependent variables.
3. Prepare the data for modeling.
4. Train the Linear Regression model.
5. Generate predictions.
6. Visualize the fitted regression line.
7. Evaluate model performance using appropriate regression metrics.
